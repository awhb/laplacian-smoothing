### Laplacian Smoothing for 3D Meshes

Runs basic Laplacian smoothing algorithm on 3D mesh inputs for a number of
iterations determined by the user.

Packaged mainly as an OpenGL 4.3 Visual Studio Solution. Development is still 
in progress for WebGL online service. 

Sample meshes can be found in subdirectory `models/`.
